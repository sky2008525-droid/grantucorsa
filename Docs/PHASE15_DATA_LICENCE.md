# Phase 15 — 実在コースのデータとライセンス

`Docs/SPEC_PHASE2_BACKLOG.md` §6 は次のように定めている。

> **ライセンスの確認を先に行うこと。** 標高データ・GPSトレース・コースレイアウトには、
> 出典によって再配布制限がある。

これはその確認の記録である。**調査日 2026-09-01。**

---

## 0. 結論（先に書く）

**このリポジトリに実在コースのデータを一切置かない。**

代わりに `Tracks/real_course.py` が「利用者が自分で用意したファイル」を読んで
コース定義に変換する。入力には**ライセンス宣言ファイルを必須**にしてあり、
宣言が無ければ変換は実行されない。

理由は3つ。

1. **標高データの中でいちばん精度が高いもの（国土地理院 5m DEM）が、
   そのまま再配布できない。** 測量法に基づく手続きが要る（§1）
2. **コースレイアウトの出所として一番手軽な OpenStreetMap は ODbL。**
   派生データベースに share-alike が伝播する（§3）
3. **リポジトリが肥大する。** バックログ §8 が Git LFS の判断を求めている
   のはこのタイミング

「置かない」は逃げではない。**置いたうえで出典を書き忘れるほうが、
後から取り返しがつかない。**

## 1. 標高データ

### 1.1 国土地理院 基盤地図情報 数値標高モデル（DEM 1m / 5m / 10m）

| 項目 | 内容 |
|---|---|
| 出典 | <https://www.gsi.go.jp/kiban/> |
| 確認したページ | <https://www.gsi.go.jp/kiban/faq.html>（FAQ Q.1-7） |
| 精度 | 日本国内で最も高い。5m メッシュが広く整備されている |
| 再配布 | **そのままは不可。** 手続きが要る |

FAQ Q.1-7 は「国土地理院が作成する基盤地図情報は、基本測量成果という位置づけに
なることから、測量法等に基づく手続が必要」としている。
具体的な条件は「測量成果の複製・使用」のページ側にあり、**用途によって
承認申請が要る。**

> **確認しきれていないこと。** 「測量成果の複製・使用」の本文までは追っていない。
> 実際に使うときは、そのページで**自分の用途が承認不要の範囲に入るか**を
> 確認すること。ここに「たぶん大丈夫」と書かない（憲法ルール2）。

**判断: リポジトリに置かない。** 利用者が自分で申請・ダウンロードして
`Tracks/Import/` に置く。

### 1.2 Copernicus DEM GLO-30（30m グローバル）

| 項目 | 内容 |
|---|---|
| 出典 | <https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM> |
| ライセンス本文 | <https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM/resources/license/License-COPDEM-30.pdf> |
| 入手 | <https://portal.opentopography.org/raster?opentopoID=OTSDEM.032021.4326.3> / AWS Open Data |
| 再配布 | **可能**（改変の有無を問わない）。ただし条件つき |

条件:

- 出典表示が必須。文言まで指定されている:
  `© DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018
  provided under COPERNICUS by the European Union and ESA; all rights reserved.`
- 再配布するときは、**後続の利用者に免責事項が伝わるようにする**こと

**判断: 条件を満たせば置ける。** ただし解像度 30m は、コースの路面形状には粗い。
サーキット1周を 30m 格子で表すと、コーナーの起伏が消える。
**「標高が入っている」ように見えて、実質は平らになる。**
広域の見た目（遠景の山並み）には使えるが、走行に効く起伏には足りない。

### 1.3 まとめ

| 用途 | 使えるもの | 備考 |
|---|---|---|
| 走行に効く路面の起伏 | 国土地理院 5m DEM | **手続きが要る。リポジトリに置かない** |
| 遠景の地形 | Copernicus GLO-30 | 置けるが、走行には粗すぎる |

## 2. GPS トレース

`.gpx` は形式であってライセンスではない。**どこから来たトレースかで決まる。**

| 出所 | ライセンス | 判断 |
|---|---|---|
| 自分で走って記録したもの | 記録した本人のもの | 置ける |
| OpenStreetMap の公開トレース | ODbL | §3 と同じ |
| Strava / Garmin Connect 等の他人の走行 | **各サービスの規約。多くは再配布不可** | 置かない |

**「ネットで拾った gpx」を出典なしで置かないこと**（憲法ルール2）。

## 3. コースレイアウト

### 3.1 OpenStreetMap

| 項目 | 内容 |
|---|---|
| ライセンス | ODbL 1.0（Open Database License） |
| 帰属 | `© OpenStreetMap contributors` |
| 問題 | **share-alike が派生データベースに伝播する** |

OSM から取ったコース中心線をリポジトリに置くと、そこから作った
`physics_test_track.json` が「派生データベース」に当たりうる。
そうなると**リポジトリ全体の配布条件に ODbL が絡む。**

このプロジェクトは今 private だが（`Docs/HANDOFF.md` §8）、
**private だから守らなくてよい規約ではない。**

**判断: 置かない。** 変換ツールは受け付けるが、出力にライセンス情報を
必ず埋め込み、利用者が判断できるようにする。

### 3.2 公式のコース図

サーキット公式サイトのコース図には著作権がある。
**トレースして「自分で描いた」ことにしない。**

## 4. この判断を実装にどう落としたか

`Tracks/real_course.py`:

- 入力ファイルと**同じディレクトリに `licence.json` を要求する。**
  無ければ `LicenceMissingError` で止まる（既定値を作らない）
- `licence.json` には `source` / `licence` / `attribution` / `retrieved` を
  必須項目として求める。空文字は通さない
- 変換結果の `_meta.licence` にそれをそのまま写す。
  **コース定義を見れば出所が分かる**状態にする
- `Tracks/Import/` を `.gitignore` に入れ、**入力データが誤ってコミット
  されないようにする**

`Tests/test_real_course.py` は、テストの中で合成した GPX を使う。
**実データを1バイトも置かない。**

## 5. まだ確認していないこと

正直に残しておく。

- 国土地理院「測量成果の複製・使用」の本文（§1.1）。
  **どの用途が承認不要かを読んでいない**
- Copernicus DEM のライセンス PDF 本文。検索結果の要約で判断しており、
  **PDF そのものは読んでいない**
- 個別サーキットの規約（走行データの公開可否など）

**この3つを確認するまで、実データを使った成果物を公開しないこと。**
