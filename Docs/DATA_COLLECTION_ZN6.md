# ZN6 車両データ収集項目リスト

> **このファイルについて**
> ZN6型トヨタ86のデジタルツイン構築に必要な情報項目を、`vehicle.json` のスキーマに合わせて整理したもの。
> RESEARCH AI への入力仕様として使う。
> 実測値・公式値・推定値を混同せず、必ず `source` と `confidence` を付けて収集すること。
>
> **重要**: このリストは全項目を最初から埋めるためのものではない。
> 物理モデルが実際に読む項目から順に埋めること（`Docs/HANDOFF.md` の Day 1 手順を参照）。

---

## 1. 基本識別情報

- メーカー / 車名 / 型式（ZN6）
- 年式 / グレード（例：2012年式 86 GT / GT Limited）
- 車両型式（DBA-ZN6 等）
- 駆動方式（FR）
- エンジン型式（FA20）
- トランスミッション形式（6MT / 6AT）
- 生産期間 / 仕向地（日本仕様 / 北米仕様 / 欧州仕様）

---

## 2. 主要寸法・重量（Source: Official優先）

- 全長 / 全幅 / 全高 [mm]
- ホイールベース [mm]
- トレッド（前 / 後）[mm]
- 最低地上高 [mm]
- 車両重量（車検証重量 / 乾燥重量 / 装備重量）[kg]
- 前軸重 / 後軸重 [kg]（重量配分）
- 乗車定員
- ホイールサイズ / タイヤサイズ（純正）
- 燃料タンク容量 [L]

---

## 3. 慣性・重心関連（Source: Estimated/Assumed も可）

- 重心高 [m]（推定含む）
- 重心位置（前後方向：フロントアクスルからの距離）[m]
- 慣性モーメント
  - Ixx（ロール）
  - Iyy（ピッチ）
  - Izz（ヨー）
- バネ上質量 / バネ下質量（前後別）
- 前後重量配分 [%]

---

## 4. エンジン（FA20）

- 形式 / 排気量 [cc]
- ボア×ストローク [mm]
- 圧縮比
- 最高出力 [PS / kW] @ [rpm]
- 最大トルク [Nm / kgf·m] @ [rpm]
- トルクカーブ（RPM vs Torque）のデータポイント（複数）
  - できればシャシダイ実測値（ホイールパワーではなくエンジン軸トルク）
- スロットル全開時の回転数ごとの出力特性
- エンジンフリクション / 内部抵抗（推定）
- 慣性モーメント（フライホイール / クランク等）
- レブリミット / アイドル回転数 [rpm]
- 燃料カット / スロットル特性（電子制御）

---

## 5. 駆動系・トランスミッション

- トランスミッション形式（6MT / 6AT）
- 各ギア比（1速～6速 / 後退）
- ファイナルドライブ比
- クラッチ形式 / クラッチ容量
- ドライブシャフト / プロペラシャフト慣性（推定）
- 駆動効率（推定）
- シフトタイム（ATの場合）/ シフトロジック

---

## 6. デファレンシャル

- 形式（オープン / LSD / トルセンデフ）
- 標準装備LSDの有無（86はトルセンLSD）
- 初期トルク / プリロード（不明な場合推定）
- アクセル側ロック率 / 減速側ロック率（LSDの場合）
- デフ容量 / 冷却（不要なら省略）

---

## 7. ブレーキ

- フロントブレーキ形式（ベンチレーテッドディスク径 / 厚み）
- リアブレーキ形式（ディスク径 / 厚み）
- キャリパー形式（フローティング / 対向）
- ピストン径 / 数
- マスターシリンダー径
- ブレーキパッド摩擦係数（推定 / 実測）
- ブレーキトルク配分（前後）
- ABS / VSC / TRC の有無と制御ロジック（公開情報 / 推定）
- 制動距離（100-0 km/h）の実測データ（可能なら）

---

## 8. サスペンション

### 8-1 形式

- フロント：マクファーソンストラット
- リア：ダブルウィッシュボーン

### 8-2 基本スペック（純正）

- スプリングレート（前 / 後）[kgf/mm or N/mm]
- ダンパー減衰力（前後 / 伸び / 縮み）[N/(m/s)]
- スタビライザー径（前 / 後）[mm]
- 車高調整範囲（純正は固定 / 車高調データも参考）
- ストローク量（バンプ / リバウンド）[mm]

### 8-3 ジオメトリ / キネマティクス（可能な範囲）

- キャンバー角（標準 / 調整範囲）
- キャスター角
- キングピン傾角（KPI）
- スクラブ半径
- トー角（前 / 後 / 調整範囲）
- ロールセンター高さ（前 / 後）
- アンチダイブ / アンチスクワット
- キャンバーゲイン（ストロークに対する変化）
- トー変化（バンプステア）
- トレッド変化

### 8-4 アライメント

- フロントキャンバー / リアキャンバー
- フロントトー / リアトー
- キャスター
- キングピン傾角

---

## 9. ステアリング

- ステアリング形式（電動パワーステアリング）
- ステアリングギア比
- ロックトゥロック回転数
- 最小回転半径 [m]
- ステアリングアシスト特性（車速感応 / トルク感応）

---

## 10. タイヤ・ホイール

- 純正タイヤサイズ（例：215/45R17）
- 純正ホイールサイズ（例：17×7J オフセット+48）
- タイヤメーカー / 銘柄（例：Michelin Primacy HP）
- タイヤ外径 / トレッド幅 / 扁平率
- タイヤ質量（推定）
- ホイール質量（推定）
- タイヤ縦バネ定数 / 横バネ定数（推定）
- タイヤ摩擦係数（μ）の範囲（実測 / 推定）
- タイヤモデル（Pacejka / Fiala / Brush）用パラメータ候補
- 荷重感度データ（垂直荷重 vs コーナリングフォース）

---

## 11. 空力

- Cd値（公式 / 風洞実測）
- 前面投影面積 [m²]
- フロント / リアのダウンフォース係数
- リフト係数（前後）
- 空気抵抗による抗力 [N] @ 100km/h 等
- 車体下面の空力（アンダーフロア / ディフューザー有無）

---

## 12. 性能実測データ（検証用）

- 0-100 km/h 加速タイム
- 0-200 km/h 加速タイム
- 最高速度
- 100-0 km/h 制動距離
- 定常円旋回横G（スキッドパッド）
- サーキットラップタイム（筑波 / 富士等）
- スラローム通過速度 / タイム
- 車両重量と馬力から計算したパワーウェイトレシオ

---

## 13. 参考資料・データソース

- メーカー公式カタログ / プレスリリース
- サービスマニュアル / 整備解説書
- 車検証 / 純正部品表
- 自動車雑誌・専門誌（ベストモータリング、Motor Fan illustrated等）
- 海外メディア（Car and Driver, Motor Trend）
- シャシダイ実測結果（インターネット公開）
- ユーザーによるサスペンションジオメトリ測定
- シミュレーターコミュニティ（Assetto Corsa等）の公開データ

---

## 14. 3Dモデル用画像・形状情報

- 外観画像（正面 / 後面 / 左右側面 / 前後3/4 / 真上）
- 内装画像（ダッシュボード / シート / ステアリング）
- ホイール・ブレーキ・ライト等のディテール画像
- 寸法が確認できる図面（可能なら）
- グレード間の外観差（バンパー形状等）が分かる画像

---

## 注意事項（収集時）

- すべてSI単位に統一（または変換可能な状態で）
- 公式値と推定値を混在させない
- 各数値にsource（Official, Measured, Estimated, Assumed）とconfidenceを付与
- 複数情報源がある場合は、信頼度の高い順に優先
- 不明な項目は「unknown」として残す
